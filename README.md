# 🌌 Nexora AI Workspace

A futuristic and fully responsive **Single Page Application (SPA)** built using **React.js**, **React Router**, **Framer Motion**, and modern UI/UX principles.

This project was developed as part of the **Codveda Technologies Internship Program** to demonstrate advanced frontend development skills, responsive layouts, animations, routing systems, and interactive UI components.
